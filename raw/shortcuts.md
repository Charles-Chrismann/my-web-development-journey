### Key glossary

`^`: CTRL key

### Terminal

`alt` + `left` or `alt` + `right`: navigate cursor to previous/next word

`^` + `a`: go to the start of the command

`^` + `e`: go to the end of the command

`^` + `k`: cut the end of the line starting from cursor

`^` + `y`: paste what has been previously cutted by `^` + `k`
